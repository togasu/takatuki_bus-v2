# バス運行便コード認証システム

## 概要
運転手がバスの運行便を設定すると6桁のコードが生成され、そのコードをauth_system（認証システム）に入力することで、認証システムの号車を設定できるシステムです。

## 使用方法

### 1. 運転手側（driverシステム）での操作

1. driverシステムにログイン
2. バス運行便設定画面 (`/bus`) にアクセス
3. 運行するバス便を選択
4. バス登録 (`/bus/register`) 画面で**6桁のコード**が表示される
5. このコードをメモまたは控える

### 2. 認証システム側（auth_system）での操作

1. auth_systemの待機画面で「**コード入力**」ボタンをクリック
2. 運転手から受け取った6桁のコードを入力
3. 「設定する」ボタンをクリック
4. 認証システムが自動的にバス情報を取得して設定完了

## 技術仕様

### データベース構造

**BusCodeテーブル（driver/instance/driver.db）**
- `code`: 6桁の数字コード（ユニーク）
- `bus_id`: バス便ID
- `busid`: バス号車番号（1-4）
- `departure_time`: 出発時刻
- `ud`: 上り(0)/下り(1)
- `expires_at`: コード有効期限
- `is_used`: 使用済みフラグ

### コードの有効期限
- デフォルト: 24時間
- コードは1回のみ使用可能
- 期限切れ・使用済みのコードは再利用不可

### API エンドポイント

**driverシステム**
- `GET /bus/register?id={bus_id}`: バス運行便設定 + コード生成

**auth_system**
- `GET /auth/code/input`: コード入力画面
- `POST /auth/code/verify`: コード検証 + バス情報設定

## セキュリティ

- コードは6桁の数字のみ
- ユニーク性保証（重複チェック）
- 有効期限管理
- 使用済みフラグで再利用防止

## トラブルシューティング

### 「コードが見つかりません」
- コードが正しいか確認
- 運転手側でバス運行便が正しく登録されているか確認

### 「このコードは既に使用済みです」
- 新しいコードを生成する必要があります
- 運転手側でバス運行便を再設定

### 「このコードは期限切れです」
- 24時間以上経過している可能性
- 新しいコードを生成してください
