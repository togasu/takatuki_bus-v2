# ドライバーデバイス管理UI - 使用ガイド

## アクセス方法

管理ダッシュボードから「ドライバーデバイス管理」カードをクリック、または以下のURLに直接アクセス:

```
https://localhost/admin/driver-devices/
```

## 主な機能

### 1. デバイス一覧の表示

- ページを開くと、登録されているすべてのドライバーとそのデバイスが表示されます
- 各ドライバーカードには以下の情報が表示されます:
  - ドライバー名
  - 登録デバイス数（X/5）
  - 各デバイスの詳細情報

### 2. ドライバーの追加

**手順:**
1. 右上の「ドライバーを選択」ボタンをクリック
2. ドライバーのユーザー名を入力（例: driver1, driver2）
3. 「表示」をクリック

既存のドライバーの場合は登録済みデバイスが表示され、新規の場合は空のカードが作成されます。

### 3. デバイスの追加

**手順:**
1. 対象のドライバーカードの「デバイス追加」ボタンをクリック
2. MACアドレス/デバイスIDを入力
   - 形式例: `AA:BB:CC:DD:EE:FF` または `AA-BB-CC-DD-EE-FF`
   - 自動的に正規化されます
3. デバイス名を入力（任意）
   - 例: 「運転席タブレット1」「予備端末」
4. 「追加」ボタンをクリック

**注意:**
- 各ドライバーは最大5台までデバイスを登録できます
- 同じMACアドレスを複数回登録することはできません

### 4. デバイスの削除

**手順:**
1. 削除したいデバイスカードの「削除」ボタンをクリック
2. 確認ダイアログで「OK」をクリック

削除されたデバイスは無効化され、そのデバイスからのログインはできなくなります。

### 5. デバイス情報の確認

各デバイスカードには以下の情報が表示されます:

- **デバイス名**: 設定した名前（未設定の場合は「デバイス X」）
- **状態**: 有効/無効のバッジ
- **MACアドレス**: デバイスの識別子
- **登録日時**: デバイスが追加された日時
- **最終使用**: デバイスが最後に使用された日時

### 6. 検索機能

ページ上部の検索ボックスにドライバー名を入力すると、リアルタイムで絞り込みができます。

### 7. 統計情報

ページ上部に以下の統計が表示されます:

- **総ドライバー数**: デバイスを登録しているドライバーの総数
- **総デバイス数**: システム全体で登録されているデバイスの総数
- **平均デバイス数**: 1ドライバーあたりの平均デバイス数

## トラブルシューティング

### デバイスが追加できない

**原因1: 最大台数に達している**
- 既に5台登録されている場合は追加できません
- 不要なデバイスを削除してから追加してください

**原因2: 同じMACアドレスが既に登録されている**
- 別のMACアドレスを使用してください
- または既存のデバイスを削除してから再登録してください

**原因3: MACアドレスの形式が不正**
- 正しい形式で入力してください（XX:XX:XX:XX:XX:XX）
- 12桁の16進数が必要です

### デバイスが表示されない

1. ページを再読み込みしてください
2. ブラウザのコンソールでエラーを確認してください
3. サーバーログを確認してください

### 権限エラーが表示される

デバイス管理には`driver_device`リソースに対する適切な権限が必要です:
- `create`: デバイスの追加
- `read`: デバイスの閲覧
- `delete`: デバイスの削除

管理者に権限の付与を依頼してください。

## デバイスログインの確認

ドライバーが登録されたデバイスからログインできるかテストするには:

1. 登録したMACアドレス/デバイスIDを確認
2. ドライバーシステムで以下のURLにアクセス:
   ```
   https://localhost/driver/{username}
   ```
3. デバイスが正しく登録されていれば、パスワード入力なしでログインされます

詳細は[device-auth-quickstart.md](./device-auth-quickstart.md)を参照してください。

## ベストプラクティス

1. **わかりやすいデバイス名を付ける**
   - ❌ 「デバイス1」
   - ✅ 「1号車運転席タブレット」「予備端末（事務所）」

2. **定期的にデバイスリストを確認**
   - 不要になったデバイスは削除する
   - 最終使用日時を確認して、長期間使われていないデバイスを整理

3. **セキュリティ**
   - 紛失・盗難時は速やかにデバイスを削除
   - 異常なログインパターンがないか監視

4. **デバイス数の管理**
   - 必要最小限のデバイスのみ登録
   - 5台の上限を超える必要がある場合は管理者に相談
