# 学期管理GUI操作ガイド

## 概要

学期管理機能はWebベースの管理画面で操作できます。管理者ダッシュボードから「学期管理」にアクセスすることで、日付ベースの学期管理とユーザー移行を簡単に実行できます。

## アクセス方法

1. 管理者としてシステムにログイン
2. 管理者ダッシュボードで「学期管理」カードをクリック
3. 学期管理画面が表示されます

## 画面構成

### 1. 現在の学期状況
- **アクティブな学期**: 現在システムで有効な学期
- **状態**: 現在の日付が学期期間内かどうか
- **更新ボタン**: 最新の状況を再読み込み

### 2. 自動学期チェック
- **自動学期チェック実行**: 現在の日付に基づいて自動的に学期切り替えが必要かをチェック
- 新しい学期期間に入っている場合、自動的に切り替えを実行

### 3. 学期一覧
- **学期名**: 学期の識別名
- **期間**: 開始日～終了日
- **状態**: アクティブ/非アクティブ、現在期間内/外
- **アクション**: 切り替え、削除

### 4. ユーザー移行管理
- **現在のユーザー数**: Userテーブル内のユーザー数
- **前学期ユーザー数**: LastSemester_userテーブル内のユーザー数
- **手動ユーザー移行**: 学期切り替えとは独立したユーザー移行

## 主な操作

### 新しい学期の作成

1. **「新しい学期を作成」ボタンをクリック**
2. **学期情報を入力**:
   - 学期名: 例「2024年春学期」
   - 開始日: 学期の開始日（YYYY-MM-DD形式）
   - 終了日: 学期の終了日（YYYY-MM-DD形式）
   - アクティブ設定: 作成と同時にアクティブにするかどうか
3. **「学期を作成」をクリック**

**注意事項**:
- 既存の学期と期間が重複しないように設定
- 通常は春学期（4月-8月）と秋学期（9月-1月）を推奨
- アクティブ設定をONにすると、既存のアクティブな学期は自動的に無効になります

### 学期の切り替え

1. **学期一覧で「切り替え」ボタンをクリック**
2. **切り替え確認画面で内容を確認**:
   - 切り替え先学期の情報
   - ユーザー移行の実行有無
3. **「学期切り替えを実行」をクリック**

**実行される処理**:
- 現在のUserテーブルのデータがLastSemester_userテーブルに移行
- Userテーブルがクリア
- 指定した学期がアクティブに変更
- 切り替え履歴を記録

**⚠️ 重要**: この操作は取り消せません！

### 自動学期チェック

1. **「自動学期チェック実行」ボタンをクリック**
2. **システムが以下を実行**:
   - 現在の日付に該当する学期を検索
   - アクティブな学期と一致するかチェック
   - 不一致の場合、自動的に切り替えを実行

**使用場面**:
- 新学期開始時の定期チェック
- 手動での学期状況確認

### 手動ユーザー移行

1. **「手動ユーザー移行実行」ボタンをクリック**
2. **確認画面で処理内容を確認**
3. **「ユーザー移行を実行」をクリック**

**注意**:
- 学期のアクティベーション変更は行われません
- データ移行のみ実行されます

## 推奨運用パターン

### 学期開始前の準備

1. **新学期の作成**:
   ```
   学期名: 2024年春学期
   期間: 2024-04-01 ～ 2024-08-31
   アクティブ: チェックしない（まだ切り替えない）
   ```

2. **学期開始日に切り替え**:
   - 4月1日に「自動学期チェック」を実行
   - または手動で学期切り替えを実行

### 定期的なメンテナンス

1. **毎月の学期状況確認**:
   - 現在の学期状況を確認
   - ユーザー数の増減をチェック

2. **学期末の処理**:
   - 手動で早めにユーザー移行を実行することも可能
   - 次学期の準備

### 自動化の設定

システム管理者は以下の自動化を設定できます：

```bash
# crontabの例（毎日午前2時に自動チェック）
0 2 * * * cd /path/to/student && python semester_cli.py auto-check
```

## トラブルシューティング

### よくある問題と解決方法

#### Q: 「アクティブな学期がありません」と表示される
**A**: 以下を確認してください：
1. 学期一覧に学期が作成されているか
2. いずれかの学期の「切り替え」ボタンを押してアクティブにする

#### Q: 学期切り替えボタンが表示されない
**A**: 既にアクティブな学期は切り替えボタンが表示されません

#### Q: ユーザー移行後にデータが見つからない
**A**: データは削除されずに`LastSemester_user`テーブルに移行されています

#### Q: 学期期間の重複エラー
**A**: 既存の学期と期間が重複していないか確認してください

### エラー時の対処法

1. **画面の再読み込み**: ページをリフレッシュ
2. **権限確認**: 管理者権限でログインしているか確認
3. **CLIでの確認**: 
   ```bash
   cd student
   python semester_cli.py status
   python semester_cli.py list
   ```

## セキュリティと権限

### 必要な権限
- **管理者権限**: `admin`ロール
- **学期管理権限**: `admin_semester_all`

### アクセス制御
- 管理者のみアクセス可能
- APIエンドポイントも権限チェック実装済み
- セッション管理による認証

## バックアップとリストア

### 重要な注意
学期切り替え前に必ずデータベースのバックアップを取ってください：

```bash
# PostgreSQLの場合
pg_dump -h localhost -U username -d database_name > backup_$(date +%Y%m%d).sql

# SQLiteの場合（開発環境）
cp student.db student_backup_$(date +%Y%m%d).db
```

## 関連コマンド（CLI）

GUIで実行される操作は、以下のCLIコマンドでも実行可能です：

```bash
# 学期一覧表示
python semester_cli.py list

# 学期作成
python semester_cli.py create "2024年春学期" 2024-04-01 2024-08-31

# 学期切り替え
python semester_cli.py switch 2

# 自動チェック
python semester_cli.py auto-check

# 状況確認
python semester_cli.py status
```

## 開発者向け情報

### APIエンドポイント
- `GET /admin/semester_management/api/semesters` - 学期一覧
- `GET /admin/semester_management/api/active-semester` - アクティブ学期
- `POST /admin/semester_management/api/create-semester` - 学期作成
- `POST /admin/semester_management/api/switch-semester` - 学期切り替え
- `POST /admin/semester_management/api/auto-check` - 自動チェック
- `POST /admin/semester_management/api/migrate-users` - ユーザー移行
- `DELETE /admin/semester_management/api/delete-semester/<id>` - 学期削除

### ファイル構成
- `admin/app/templates/semester_management.html` - GUI画面
- `admin/app/routes/semester_management.py` - 管理者側ルート
- `student/app/routes/semester_api.py` - API実装
- `student/app/utils/semester_utils.py` - ビジネスロジック
- `student/app/models/semester.py` - データモデル
